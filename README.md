# 威力彩號碼機率分析與預測 🎱

基於台灣彩券官方資料的威力彩（SuperLotto 638）歷史開獎號碼統計分析網站。

## 🌐 線上網站

**https://japan5387690.github.io/superlotto/**

## 📊 功能

- **號碼出現機率**：第一區（1–38）與第二區（1–8）每個號碼的歷史出現次數與機率，含長條圖視覺化。
- **冷熱號分析**：熱號（最常開出）、冷號（最少開出）、遺漏值（最久未開出）、近期熱門（最近 50 期）。
- **下期號碼預測**：四種統計策略
  - 策略 A — 頻率法：歷史出現頻率最高
  - 策略 B — 冷號回補法：遺漏期數最久
  - 策略 C — 近期趨勢法：最近 50 期最熱
  - 策略 D — 加權混合法：歷史頻率 60% + 近期趨勢 40%
- **整體型態統計**：平均和值、奇偶比、大小比等。
- **近期開獎紀錄**：最近 30 期完整號碼。

## 📈 資料

- **資料來源**：台灣彩券股份有限公司官方 API
- **涵蓋範圍**：2008-01-24（首期）至今，共計約 1900+ 期完整開獎資料
- **威力彩規則**：第一區 1–38 選 6 個號碼，第二區 1–8 選 1 個號碼；每週一、週四開獎

## 🔄 更新資料

```bash
python3 fetch_data.py   # 重新抓取最新開獎資料 → draws.json
python3 analyze.py      # 重新計算統計 → stats.json
python3 build_stats_js.py  # 產生前端用 stats.js
```

## ⚠️ 免責聲明

本網站僅供**統計研究與娛樂**用途。樂透開獎為**獨立隨機事件**，每一期每個號碼的中獎機率皆相同且固定，過往出現頻率**無法**預測未來開獎結果。所謂「預測號碼」僅為基於歷史數據的統計趣味推算，不具任何中獎保證。**理性購彩，量力而為。**
